# CardViewApp - Professional Learning UI 🚀

A modern, high-performance Android application template for educational platforms. This app focuses on a premium "Dark Mode" aesthetic, smooth user interactions, and robust data management.

## ✨ Key Features

- 🌑 **Premium Dark Mode**: Deep blue aesthetic designed for focused learning.
- 📱 **Adaptive Layouts**: Responsive Grid and List views for course exploration.
- 👤 **Cool Profile Dashboard**: Tracks overall progress, course counts, and bookmarked items.
- 🔖 **Smart Bookmarks**: Persistent bookmarking system powered by **Room Database**.
- 🔍 **Dynamic Search**: Real-time course filtering by title and category.
- 📊 **Progress Tracking**: Visual progress bars for every course.
- 🚀 **Smooth UX**: Fall-down item animations and Facebook Shimmer loading effects.
- 🖼️ **Optimized Imagery**: Image caching and circular cropping using **Glide**.

## 🛠 Tech Stack

- **Architecture**: MVVM (Model-View-ViewModel)
- **Persistence**: Room Database
- **Networking/Images**: Glide
- **UI Components**: Material 3, CoordinatorLayout, ShapeableImageView, SwipeRefreshLayout
- **Effects**: Facebook Shimmer API

## 🚀 Installation

1. Clone the repository:
2. **Open in Android Studio**: Recommended version **Ladybug** or newer.
3. **Sync Gradle**: Let the dependencies download.
4. **Run**: Deploy on an emulator or physical device (API 24+).
